# Auto Argo Node

外部订阅现支持名称清理、已验证 IPv4 对照与上游账户用量显示，详见 [外部来源整理](docs/external-source-transformations.md)。

独立 Monitor 探针已移除并保留备份，节点脚本负责心跳、流量和管理。流量与 TG 通知已迁回主面板。详见 [探针移除与恢复](docs/monitor-removal.md)。

服务器档案、同机新增节点、分步骤重装恢复、统一任务进度、主备管理地址与订阅故障隔离的操作说明见 [服务器工作区](docs/server-workspace.md)。

通过网页选择 **VLESS-WS + Argo、VLESS TCP Reality Vision 或 Hysteria2**，生成一次性安装命令，在自己的服务器部署并集中管理节点。

节点可通过安装命令主动连接面板，也可在「SSH 运维」中录入凭据后按需管理；使用安装命令无需提供 SSH 密码。节点安装脚本内置每分钟 cron 心跳、服务检查与流量采集；远程管理可按需启用。Argo 使用出站隧道；Reality 和 Hysteria2 需要对应 TCP / UDP 端口可达。

## 功能

- 自定义名称、本地监听端口、优选域名/IP、客户端 HTTPS 端口、UUID 和 WebSocket 路径。
- 一次性安装凭据，有效期 24 小时；安装完成后换成仅对应节点可用的运行凭据。
- 自动同步临时隧道域名及 VLESS 链接，可勾选节点生成订阅，不生成节点二维码。
- 编辑节点参数；修改监听端口时排队执行，确认成功后才更新面板实际端口。
- 连续异常检测、隧道重建、离线提示及面板侧实际 VLESS 转发测试。
- 远端卸载成功后删除面板记录；同机其他节点及仍在使用的共用服务保留。
- 用户名和密码登录，保留登录限速及会话验证。
- 左侧导航切换独立模块页面，保留节点与任务明细折叠；支持服务器集中管理、精简核心及回滚。

## 环境要求

**面板服务器：** Docker Engine、Docker Compose，以及一个节点服务器能访问的 HTTPS 域名。默认只监听 `127.0.0.1:18899`，通过 Nginx 等反向代理提供 HTTPS。

**节点服务器：** root 权限、systemd 或 OpenRC，以及可访问面板、GitHub 和 Cloudflare 的出站网络。

| 项目 | 支持范围 |
| --- | --- |
| 系统适配 | Alpine、Debian、Ubuntu |
| 架构适配 | 精简/固定原版核心支持 AMD64、ARM64；旧版上游路径另有 ARMv7 支持 |
| 本地监听 | Argo 默认环回监听；Reality / Hysteria2 按协议配置 TCP / UDP 监听 |
| 客户端端口 | Argo 使用 Cloudflare 支持的 HTTPS 端口；直连协议使用实际可达端口 |
| 节点依赖 | Shell、curl、jq、flock、cron，由安装命令安装必要依赖 |

三协议已通过隔离 Alpine / AMD64 / OpenRC 安装、真实转发及卸载验证；精简核心已在 Alpine、Debian、AMD64、ARM64 试点验证。节点脚本每分钟运行后退出，sing-box 及 Argo 的 cloudflared 持续运行；独立探针已卸载，详见 [移除与恢复验收](docs/monitor-removal.md)。

## 部署面板

```sh
git clone https://github.com/zhangx16/auto-argo-node.git
cd auto-argo-node
cp .env.example .env
```

编辑 `.env`，将 `PANEL_URL` 改为实际访问地址，例如 `https://panel.example.com`。不要填写节点地址；这是面板自己的公开地址。

先在面板或独立构建机准备核心文件；节点服务器无需编译器。构建结果位于 `artifacts/releases`，由面板提供下载，默认精简通道依赖这些文件。若使用独立构建机，请将该目录复制到面板项目的同名目录。

```sh
sh scripts/build-minimal-core.sh
docker compose up -d --build
curl -fsS http://127.0.0.1:18899/health
```

构建时会从上游下载并校验固定版本的安装脚本，需要访问 GitHub。应用状态保存在 `./data/`。当前不需要 Monitor hub 或附加 Compose 文件；已有旧部署请参阅 [探针移除说明](docs/monitor-removal.md)。

配置 HTTPS 反向代理，可参考 [Nginx 示例](docs/nginx.conf.example)。替换域名、证书路径；如果更改了 `.env` 中的 `PANEL_PORT`，同时修改代理目标端口。示例不自动申请证书，请使用已有效的证书或通过自己的证书工具配置 HTTPS。

浏览器登录需要 HTTPS，应用的登录 Cookie 带有 `Secure` 属性。域名和 HTTPS 配置好后访问面板。

### 首次登录

默认账号 `admin`，密码随机生成。在面板服务器本地查看：

```sh
sudo cat data/credentials.txt
```

当前登录使用用户名和密码，无需绑定验证器。`ADMIN_USER`、`ADMIN_PASSWORD` 仅在空数据目录首次初始化时生效，修改 `.env` 不会覆盖已有账号密码。

`data/credentials.txt` 包含首次初始化的明文密码，登录完成并妥善保存后可删除；不要公开该文件、`.env` 或整个 `data/` 目录。

### 配置项

| 变量 | 说明 |
| --- | --- |
| `PANEL_URL` | 必填，节点可访问的面板 HTTPS 地址 |
| `PANEL_BIND` | 宿主机监听地址，默认 `127.0.0.1` |
| `PANEL_PORT` | 宿主机监听端口，默认 `18899` |
| `TZ` | 时区，默认 `Asia/Shanghai` |
| `ADMIN_USER` | 首次初始化账号，默认 `admin` |
| `ADMIN_PASSWORD` | 首次初始化密码，留空自动生成 |
| `ORIGIN_IP` | 旧版 Reality 安装回调可选直连地址，正常 Argo 管理无需填写 |

## 部署和管理节点

1. 在“配置部署”填写参数，点击“生成安装命令”。
2. 在目标节点服务器以 root 执行该命令。
3. 点击左侧“服务器”，打开对应服务器小窗，在协议节点中查看详情、检测结果及连接链接。
4. 在服务器小窗的“任务记录”查看执行进度和日志；已有服务器可直接点击“新增节点”，复用 SSH 配置。
5. 节点脚本负责心跳和流量采集；远程管理未启用时，修改或卸载需手动执行面板给出的命令。

优选地址默认留空，直接使用当前临时隧道域名，也可填写自己的优选域名或 IP。优选地址只改变客户端连接目标；TLS SNI 和 WebSocket Host 使用当前临时隧道域名。

- **修改名称、优选地址、客户端端口：** 立即更新面板链接。
- **修改本地监听端口：** 已启用管理时节点下次连接执行，否则执行面板提供的手动命令；新隧道验证后停止旧隧道，失败尝试恢复旧配置。临时域名会变化，请重新复制链接。
- **重新生成安装命令：** 使尚未使用的旧命令失效；命令实际执行完成绑定后，旧运行凭据失效。
- **已有旧版 SSH 部署节点：** 先点击“接入监控”，到该节点执行一次接入命令，再通过主动上报方式管理。原一次性 SSH API 继续兼容旧部署；长期 SSH 管理使用新增「SSH 运维」页面，凭据单独加密保存。
- **删除节点：** 确认后排队卸载对应隧道、监听配置、监控凭据及 cron。收到成功确认后删除记录。离线节点保持“卸载中”，恢复连接后处理；无安装内容的未执行任务可直接删除。正在执行配置的任务需要等待结束。

不要在远端节点尚未卸载时直接销毁面板数据，否则面板会失去继续调度清理的凭据。

## 订阅管理

展开主页“订阅管理”并点击“创建订阅”，填写名称，勾选要导出的已部署节点。支持多个独立订阅，每个订阅只包含明确选择的节点，新部署节点不会自动加入。

| 格式 | 用途 |
| --- | --- |
| 通用 Base64 | Base64 编码的节点 URI 列表 |
| 原始节点链接 | 每行一条，可继续导入 Sub-Store 等工具处理 |
| Clash / Mihomo | 包含节点、选择组和基础全局代理规则的 YAML，需支持 VLESS 的 Mihomo 客户端 |
| sing-box | 包含 mixed 入站、选择出站、DoH DNS 及基础路由的 JSON（sing-box 1.12+） |

sing-box 基础配置使用 Cloudflare `1.1.1.1` 的 HTTPS DNS，并通过直连出站解析节点域名；可按自己的网络环境调整 DNS。

Clash/Mihomo 与 sing-box 基础配置的本地代理监听端口为 `127.0.0.1:7890`；Clash 使用 `allow-lan: false`。下载配置会替换客户端导入的相应配置，复杂分流规则可通过客户端或其他管理工具另行配置。

每个订阅可选择格式复制地址、预览内容、下载配置、修改节点选择、停用、设置到期时间或重置地址。重置后旧地址立即失效；删除订阅不会删除节点。允许先保存空订阅，尚无可导出节点时返回错误，不会生成静默直连配置。

订阅地址是不需要面板登录的访问凭据，持有者可读取该订阅的节点配置。它只允许读取对应订阅，不具备面板管理能力；不要公开分享到公共仓库。

订阅内容在每次请求时读取节点最新数据，优选地址、SNI、WS Host、路径与 Early Data 参数会保留。临时隧道域名更新后，客户端需刷新订阅才能取得新配置。卸载中或已删除节点自动排除；短暂离线节点保留在选择中，避免网络波动改变客户端配置。

这一功能参考 [妙妙屋](https://github.com/iluobei/miaomiaowu) 的节点选择/生成订阅方式及 [Sub-Store](https://github.com/sub-store-org/Sub-Store) 的多格式订阅管理思路，独立实现于本项目中，无需部署第三方转换服务。转换字段参照 [Mihomo VLESS 文档](https://wiki.metacubex.one/en/config/proxies/vless/) 和 [sing-box VLESS 文档](https://sing-box.sagernet.org/configuration/outbound/vless/)。

### 客户端链式代理

编辑或创建订阅，先勾选至少两个自建/外部节点，再点击“添加链路”，按入口 → 中转 → 出口排列。流量顺序是本机 → 第一跳 → … → 最后一跳 → 网站，网站看到的是出口节点的地址。支持每条链路 2–5 跳、每个订阅最多 30 条链路；可调整顺序、替换节点或删除链路。

“只展示链式节点”默认在新增链路时选中，导出的选择组仅提供完整链路，没有单节点或直连选项。取消勾选可同时保留普通节点，默认选项仍优先使用链路。Hysteria2/TUIC 位于入口之后时，上游需要支持 UDP 转发。

含链路的订阅仅导出 Clash/Mihomo 或 sing-box 完整配置；普通 URI/Base64 无法表达链路关系，服务端会明确拒绝这些格式。切换为链式订阅后，请在客户端导入对应格式地址。配置分别使用 [Mihomo dialer-proxy](https://wiki.metacubex.one/config/proxies/dialer-proxy/) 与 [sing-box detour](https://sing-box.sagernet.org/configuration/shared/dial/)；各链路使用独立节点副本，不修改普通节点定义。

链路实时读取节点最新地址、端口和凭据。任一跳被删除、停用或卸载时，整个订阅导出会报错，并在面板提示修复，不会跳过该跳或自动改为直连。短暂离线节点仍保留配置，实际连接取决于客户端网络。这一功能仅改变订阅客户端配置，不修改节点服务器上的路由或上游。

### 导入外部节点

在“订阅管理”点击“导入外部节点”，可粘贴链接/订阅内容、上传文件，或填写外部订阅 URL。点击“解析预览”，勾选需要的节点后确认导入；再编辑或创建订阅，勾选这些外部节点即可与自建节点混合导出。

- 协议：VLESS、VMess（Base64 JSON）、Trojan、Shadowsocks、Hysteria2/Hy2、TUIC v5。
- 格式：一行一条 URI、Base64 URI 列表、Clash/Mihomo YAML、sing-box JSON。
- 传输：常见 TCP、WebSocket、gRPC；保留 TLS、Reality、WS Host/路径/Early Data 等已支持参数。
- 导入前提供预览与错误项提示；按连接配置去重，节点名称不同不会重复新增。
- 「解析预览」中的 URL 仅拉取一次；需要持续同步时，在「外部订阅定时更新」单独添加来源，URL 加密保存。文件和拉取内容上限 1 MiB，一次最多 1000 项。
- 外部节点可编辑名称与链接、启用/停用或删除；修改会影响引用它的订阅。删除只清理面板记录与订阅引用。
- 外部节点不加入部署任务，不进行 SSH 安装、云隧道重建或本地节点代理测活。

插件、链式代理、端口跳跃及部分高级选项暂不支持，会在预览中标为不支持；不会将第三方配置中的规则、DNS、代理组或脚本导入面板。URL 拉取仅允许公网 HTTP/HTTPS，逐跳校验并固定 DNS 解析结果，阻止本机、内网和保留地址。

## Reality Vision 与 Hysteria2

在“配置部署”的“节点类型”中选择协议，填写公网地址、本地监听端口、公网/NAT 映射端口及 TLS/伪装域名，再生成安装命令。公网端口可与本地端口不同；Reality 放行 TCP，Hysteria2 放行 UDP。它们直接连接服务器，不使用 Cloudflare 隧道或优选地址。

- Reality 使用 VLESS TCP、`xtls-rprx-vision`、自动生成的 Reality 密钥和 Short ID。私钥只保留在节点服务器。
- Hysteria2 沿用安装器的自签名证书方式，密码自动生成，链接与订阅携带对应的证书验证设置。当前适配基础单端口模式，不包含跳跃端口与 Salamander 混淆。
- 两种节点均支持一次性安装、按节点令牌上报、状态查看、名称/公网地址/映射端口编辑、监听端口修改、重新读取及卸载。监听端口变更失败会保留原连接配置；成功后同步新链接。Reality 密钥、UUID及 Hysteria2 认证信息保持不变。
- 多个节点共享 sing-box，修改与卸载仅操作对应入站；最后一个入站删除后清理服务。支持与 Argo 和外部节点混合勾选导出订阅。
- 每分钟检查进程与本地 TCP/UDP 监听；连续故障后重启服务。面板按协议使用临时客户端验证实际 HTTPS 转发，最多并发两个，完成即退出，不在节点服务器增加常驻监控客户端。

已在隔离 Alpine/AMD64/OpenRC 环境验证安装、真实转发、端口冲突回退、TCP/UDP 端口修改、服务修复、共享服务卸载和四种订阅格式。Debian/systemd 与 ARM 仍需对应机器实测。

## 临时与固定 Tunnel

已接入主动监控的临时隧道节点可由管理员 API 迁移至 Cloudflare 远程管理的固定 Tunnel。每个节点独立创建 Tunnel 和未使用的一级子域名；保留 UUID、WS 路径、监听端口及订阅引用，固定域名通过公网 WebSocket 验证后才停止旧临时连接。

管理员先通过 `PUT /api/cloudflare` 配置 `account_id`、`zone_id` 与 `api_token`，再调用 `POST /api/agent-nodes/{id}/fixed`，请求体为 `{"hostname":"node01.example.com"}`。这些接口要求面板登录，并校验请求来源；凭据需具有指定账户的 Tunnel 编辑及指定 Zone 的 DNS 编辑权限。现有 DNS 记录不会被覆盖。旧监控脚本会先通过配置任务自动升级。

主页“配置部署”可选择临时或固定隧道，默认使用临时隧道。固定模式可填写当前 Zone 下的完整一级子域名，留空自动分配 `node-编号.example.com`。安装时自动创建专属 Tunnel 和 DNS，直接安装固定连接，不经过临时隧道。已部署节点和部署任务在名称旁显示隧道类型标签；临时节点迁移仍可通过管理员 API 操作。固定节点允许修改名称、优选地址和客户端端口，暂锁定本地监听端口。失败的迁移可在任务中重试，未完成的云端资源保留给重试或删除清理。

固定隧道失效时重启同一 Tunnel，域名保持不变。删除节点等待远端卸载成功并清理面板创建的 DNS 与 Tunnel 后，才删除记录；云端清理失败会保留任务等待重试。迁移首次改变域名后，客户端需刷新一次订阅。

API Token 与每节点运行凭据使用面板 `secret.key` 派生的密钥加密存储，远端仅保存自身 Tunnel 的 root 专有凭据文件。备份与恢复必须同时保留数据库和对应的 `secret.key`。

## 测活与自动修复

节点脚本每分钟检查 cloudflared 进程、本地 WS 握手及公网隧道 WS 握手并上报。连续 3 次失败、距上次修复至少 300 秒，才尝试修复；服务器整体出站网络异常时暂不反复重建隧道。

本地服务异常先重启 sing-box；公网隧道异常尝试重建 cloudflared。临时域名变化会更新节点元数据并同步面板链接。新域名可能需要额外一轮检查才能正常访问。

- 超过 180 秒未收到心跳，显示“心跳超时”。
- 面板每 5 分钟独立进行一次实际 VLESS-over-WS + TLS + HTTPS 转发测试，最多并发 2 个；也可手动测活。
- 失败的常规配置任务不会每分钟反复重装，需要手动点击“重试任务”；卸载失败会保留记录和日志，等待下一次连接重试。

心跳、WS 检查、真实转发结果分别显示，不能保证所有客户端地区的可用性。临时隧道不保证域名固定或长期可用。

## 升级与备份

先确认没有正在执行的部署/卸载任务。更新前备份 `.env` 和完整 `data/`；其中包括数据库、会话密钥、加密凭据及节点凭据哈希。当前登录使用用户名和密码，不要求 2FA。使用 Monitor 时也需保留其数据与部署配置。

简单一致性备份方式是短暂停止面板，再归档数据：

```sh
docker compose stop
sudo tar -czf ../auto-argo-node-backup.tar.gz .env data
docker compose start
```

备份会包含敏感信息，应保存在私有位置。不要将生产数据提交 GitHub。恢复时需使用同一份数据库与 `secret.key`，并保留文件权限。

```sh
git pull --ff-only
```

### 流量与 Telegram 通知

主面板「流量与通知」支持配置 Bot、查找最近聊天、测试通知、设置心跳超时与流量汇总间隔。Bot Token 仅在面板端加密保存，节点不接触通知凭据。心跳停止默认 180 秒，异常/恢复采用状态去重与短暂防抖；通知队列最多 200 条、最多重试 8 次。面板自身停机时无法发送通知。

节点 v4 脚本复用现有 Shell + cron，每分钟读取独立 `inet argo_traffic_<节点ID>` 的 nftables 端口计数器并随心跳上报，不新增常驻进程，不修改流量放行/丢弃策略。老节点点击「更新轻量监控脚本」即可升级，不改端口、UUID 或隧道。缺少 nftables 或 NET_ADMIN 的 NAT 容器会显示未采集，节点代理仍可运行。卸载会删除对应统计表；强制删除仍仅移除面板记录。

按节点显示今日、本月和累计 IN/OUT，UTC 日界线，最多保留 400 天日汇总，不存每分钟历史。首次采样建立基线，后续通过累计计数差值防止重复上报；重启或规则重建会切换计数代次。Argo 统计本地隧道与 sing-box 的监听端口流量，直连协议统计其监听端口；这是端口统计，包含握手/健康检查，不等于云厂商网卡账单。断电前未上报的流量可能丢失。

面板安装库由固定上游提交裁剪为三协议依赖闭包，保留配置事务、密钥校验、服务管理、下载校验和恢复路径，删除其他协议的安装菜单、二维码与无关功能。`scripts/node-library-manifest.json` 记录来源与保留函数。`sb` 命令仅提供面板提示和既有维护入口，节点安装/编辑/卸载通过面板执行。

### 用量图表、地区国旗与订阅用量

「流量与通知」新增按 UTC 日期的堆叠柱状图：横轴日期、纵轴用量，区分端口 IN/OUT，支持近 7/30/90 天及单节点筛选，并提供每日数据表。未采集日期明确标注，不冒充实际零用量。图表只读取现有日汇总，无额外节点进程。累计总量独立持久化，不随 400 天图表历史清理而回退。

面板内置 DB-IP Country Lite 2026-10 本地 IP 库，以 mmap 方式读取；不向第三方查询服务发送服务器 IP。自建节点以主动上报的服务器公网 IP 识别，避免把 CF 优选地址当成节点地区；外部节点以连接地址识别。结果缓存，域名仅由后台限量解析。节点展开后的「设置地区」支持人工覆盖和恢复自动识别；国旗用于展示与订阅节点名，原始名称、密钥、地址和端口不改变。IP 库结果存在误差，外部节点经过 CDN 时可能识别到 CDN 地区。数据来源：[IP Geolocation by DB-IP](https://db-ip.com)，CC BY 4.0；构建时下载并校验固定版本，`GEOIP_PATH` 可指向管理员提供的兼容 MMDB 文件。

订阅展示所选自建节点**自启用采集以来的共享端口用量**，不是按订阅、客户端或用户独立计费。相同节点被多个订阅引用时，它们看到同一份节点累计值；链式订阅对参与链路的不同自建节点分别计数，同一节点重复引用只计一次。外部节点无法采集、未接入采集和过期状态都会显示。订阅节点选择变化后，汇总范围同步变化。

导出响应携带标准 `Subscription-Userinfo` 的 upload/download/total/expire 信息，供支持该响应头的客户端显示（随客户端更新订阅刷新）。未采集到任何自建节点时不伪造零用量。可选「展示额度」仅作为面板和客户端参考，不会中断转发或限制流量。节点端仍复用既有 Shell + cron，无新增依赖或监控进程。

### 事件时间线、流量结算与配置保护

展开节点后可查看「故障详情 / 维护」中的事件时间线：心跳停止/恢复、代理进程及本地/公网检查、实际协议转发、任务、自动修复与额度提醒。状态相同不重复记录，记录不依赖 Telegram 开关；仅记录功能启用后的变化，不补造历史。保留 90 天、全局最多 5000 条，节点删除时级联清理。

「流量额度」可设置每周期额度（GiB）、每月结算日、提醒阈值和 IN/OUT/双向口径。结算按 UTC 00:00，29–31 日在短月份取月末，下一月仍按原指定日结算。用量复用已有日汇总，新周期只改变汇总范围，不清空历史和累计值；首次采集前及未成功采集的用量无法补齐，不等于厂商账单。额度为 0 关闭提醒；不自动停用节点。启用并绑定 Telegram 后，提前阈值与额度用尽分别每周期提醒一次（阈值为 100% 时只提醒一次），规则实际改变后重新判断。

已绑定节点修改连接地址、客户端端口或可修改的监听端口时，面板会临时加密保存一份修改前配置。原链接在 10 分钟内通过测活、且心跳未超时，才启用转发验证失败后的自动回滚；否则保留修改结果并显示「原配置未经测活确认」，避免把失效地址当作有效配置恢复。远端脚本执行失败仍保留其原有本地事务恢复机制，并恢复匹配的面板参数。

新配置连续两次转发验证失败后，面板恢复原连接参数；涉及已应用的监听端口时，下发新的递增版本任务，等待节点恢复监听，再验证实际回传链接。临时隧道可能重新分配域名，因此恢复连接参数不代表恢复旧临时域名。恢复后再次失败便停止，不循环回滚。变更期间拒绝新的编辑及无关配置任务，过期探测和重复回调不能覆盖新配置。检查点在变更终结后擦除，不生成磁盘备份快照。

保护范围为节点编辑中的连接参数和监听端口；Cloudflare 账号、DNS 和临时转固定迁移继续使用原有迁移脚本事务保护，不自动撤销云端资源操作。节点离线时无法保证立即完成远端恢复，面板会显示等待状态。

### 汇总已有订阅与节点管理

创建或编辑订阅时可勾选「引用已有订阅」，自动继承原订阅后续节点变更，合并时按完整连接参数去重并保留不同账户。用量按原订阅分开展示，可指定客户端显示哪个来源的统计；自动模式遇到多来源时不伪造合计额度。来源停用、到期、删除和配置异常均有提示，链式代理与原订阅故障隔离规则保留。

节点收纳在订阅折叠区内，以紧凑网格显示；未加入订阅的外部节点单独保留。外部节点可单个或批量全局删除，删除前提示影响范围，来源刷新不会自动加回；仅调整某一订阅请编辑成员选择。[完整规则与接口](docs/subscription-composition.md)。

### 订阅专属页面

订阅操作中的「订阅专属页面」和「复制页面地址」提供独立分享入口。持有页面地址即可查看该订阅的可用节点/链路、展示额度、共享节点用量和到期时间，复制或下载四种现有格式，并通过 Clash/Mihomo 或 sing-box 的 URL Scheme 导入。页面与订阅共用令牌、停用和到期机制；重置地址同时使旧页面及旧订阅 URL 失效。页面不含服务器管理参数，不加载外部资源，使用 no-store、no-referrer 和 noindex。仍不生成二维码。

### 外部订阅定时更新

订阅模块 → 外部节点 →「外部订阅定时更新」可添加最多 50 个来源，默认每 6 小时检查，可设置 15 分钟至 7 天，也可手动更新或暂停。URL 使用面板密钥加密保存，编辑时留空保留，接口不回显原 URL。沿用公共地址校验、每跳 DNS 固定、25 秒及解压后 1 MiB 的拉取限制；一次最多解析 1000 个节点，同步在本机单工作线程运行。

- 同一来源按连接身份优先匹配，名称唯一时支持地址/凭据变化后保留节点 ID；名称和连接参数同时改变、或重名无法确定身份时按新节点处理。
- 各来源独立维护节点，避免一个来源覆盖另一个来源或手工节点。保留手动名称、地区、分组标签、启停状态和订阅引用；手动修改连接参数后，自动更新保留本地配置。
- 上游缺失节点保留记录但暂不导出；重新出现后恢复来源可用性，不覆盖手动停用。解析为空、包含无效项或更新冲突时整个更新不应用，保留先前节点。
- 手动删除的节点在该来源中记为忽略，可点击「恢复被删除节点」重新允许导入；名称与连接参数都变化时无法可靠关联旧忽略记录。
- 可显式选择将新增节点加入哪些面板订阅；默认不选。取消目标关联不会删除已加入节点，仍可在订阅编辑中调整。删除来源停止调度、删除加密 URL，保留节点；原先缺失节点转为手动停用。

### 分组标签与流媒体解锁检测

自建及外部节点均可设置一个分组和最多 12 个标签，用于列表筛选与订阅节点搜索，不改写节点名称或连接配置。

节点操作中的「流媒体 / AI 检测」支持 Netflix、Disney+、YouTube Premium、Prime Video、Apple TV、Spotify、YouTube、TikTok、ChatGPT、Gemini、Claude、Grok。默认选择原有四项，可单选或全选。检测完全在**面板服务器**运行：按需启动现有 sing-box 探测内核，经所选节点建立显式 HTTP CONNECT 请求，不使用环境代理或回退为面板直连。一次一个任务、最多两项并行，最多 60 秒，每个响应最多读取 1 MiB，不登录账号或下载播放媒体；关闭弹窗仍运行，可重新打开取消。进程与私有临时配置在完成、失败、取消时清理。节点端脚本和依赖不变，无新增常驻进程。

结果区分可用信号、入口可访问、部分可用、地区受限、未知、未完成和网络/接口异常，展示服务返回的地区。Netflix 使用抽样片库信号，Disney+ 使用匿名设备地区接口，YouTube Premium 与 Prime Video 使用服务页面的地区/可用性字段。风控、验证码、限流、缺字段和超时不等于未解锁；区域可用信号不保证账号、会员、DRM 或实际播放。平台接口变化可能导致未知，历史结果不会承诺持续有效。每节点最近 5 次，全局最多 200 条；连接配置变化后标为过期，删除节点同步删除检测记录。

参考项目与实现选择见 [流媒体检测方案](docs/media-check-design.md)。

新增 AI 项目检测免登录网页入口和明确的地区错误，Cloudflare trace 地区只作为来源信息，不能单独证明账号、API 或模型可用；不发送对话或付费请求。Apple TV 单独检查 TV 入口，Apple 定位地区不等同于 TV 订阅解锁。Spotify 不提交注册或创建账号。达到总时限的项目标为未完成，历史按请求顺序排列。

### 轻量心跳、本地诊断与精简核心

节点安装脚本通过每分钟 Shell + cron 上报心跳、本地服务与协议端口流量，不增加独立资源探针常驻进程。面板侧复用实际协议转发检测和自动修复保护。服务器本地执行 `sh /usr/local/lib/argo-deploy/diagnose.sh <节点ID>` 可进行只读诊断，不输出节点凭据。

支持精简 / 原版 sing-box 核心安装、切换及回滚。[核心内存对比测试](docs/core-memory-benchmark.md) 保留三协议实测、参照数据及复现脚本；历史 Monitor 设计仅作归档，当前行为以 [探针移除说明](docs/monitor-removal.md) 为准。

### Telegram 消息优化

支持按类别选择提醒、状态图标与粗体字段、地区旗帜、恢复耗时、面板按钮，以及带 TOP 5 条形图的运行与流量简报。新增任务、修复与回滚、订阅到期、外部来源连续失败和持续资源压力提醒，全部在面板执行。[通知规则与去重说明](docs/telegram-notifications.md)。

### 协议流量与通知

全局流量、节点额度和 Telegram 设置位于主面板“流量与通知”；服务器小窗提供对应主机协议节点的流量汇总。整机网卡流量卡片、拖动排序与主题看板随独立探针移除，不再作为当前功能提供。

Telegram 左侧菜单支持 `/start`、`/status`、`/nodes`、`/traffic`、`/help`，仅向已绑定聊天提供查询，通知时间使用北京时间（UTC+8）。

### 运维中心、维护模式与分批升级

支持单节点 / 服务器维护、持久化自动修复上限、分层故障详情与诊断导出、面板健康检查、版本展示和逐台升级。管理脚本 v8 在修复前申请授权，默认 60 分钟最多 3 次，达到上限后需手动解除；旧脚本需升级才能完整生效。核心继续使用已有验证与回滚机制。详见 [操作说明与边界](docs/operations-center.md)。

### SSH 按需运维

现有资源服务器自动显示为「待填写 SSH 凭据」，首次由管理员在网页输入 root 密码或私钥并核对主机指纹。支持独立管理密钥、只读诊断、自定义维护、首次安装、按需执行已有节点任务及管理通道切换；不自动使用聊天中曾提供的密码。节点脚本负责心跳，SSH 只在执行任务时连接。详见 [SSH 操作说明、恢复机制与验证边界](docs/ssh-operations.md)。
