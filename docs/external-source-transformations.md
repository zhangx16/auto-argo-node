# 外部订阅整理与上游用量

外部来源支持客户端标识（面板默认、Clash/Mihomo、sing-box）、名称前缀清理、经过验证的 IPv6 → IPv4 对照和暂不导出未映射 IPv6 节点。设置保存在来源，定时更新继续应用；编辑来源可修改地址对照。

- 前缀清理仅移除名称开头的“测试 / 优化 / 直连 / 家宽”标签，可连续清理，不删除倍率后缀或名称中间的词。
- 地址对照只接受 IPv6 到公网 IPv4，不能从数字形式直接换算。先通过原 IPv6 节点查询 IPv4 出口，再使用候选 IPv4、原端口和原认证测试真实代理转发；出口地址不必然是可接入地址。
- 原 TLS SNI、协议凭据、端口和传输配置保持原值。只有验证通过的对照才录入；以后来源新增没有对照的 IPv6，可选择暂不导出，避免自动恢复成 IPv6。
- 定时刷新保留节点 ID、选择状态与手工覆盖，来源更新失败保留原有数据。

来源拉取时读取标准 `Subscription-Userinfo`，仅保存有效的非负 upload / download / total / expire 数字，不保存其它响应头。订阅地址仍加密保存，编辑表单不回显。

当订阅仅包含一个来源的外部节点时，面板、专属订阅页和客户端订阅头使用该来源的账户用量、总额及上游到期时间。选择部分节点也显示整个上游账户用量，不能冒充单节点或本面板独立用量。同一来源无论有多少节点都只计算一次。混合多个来源或自建节点时，上游账户统计单独列出，避免与本地端口统计相加。

本次导入创建独立订阅“外部订阅 · IPv4”，29 个节点，12 个纯 IPv6 地址以实际转发验证的 IPv4 替换，其余包含一个原有域名（具备 A 记录）。上游名称标签均清理，倍率保留，按上游建议每日更新。原有 CF 订阅和外部节点未改动；相同服务器但凭据不同的节点视为不同账户，不覆盖原记录。

测试包括前缀、IPv4 对照校验、认证与 SNI 保留、更新后节点 ID 稳定、账户用量去重、子集 / 混合来源、订阅头与旧编辑器兼容。生产浏览器验证面板、来源编辑不回显 URL、专属页和移动端显示。
