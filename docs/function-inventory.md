# 当前功能清单（2026-10-25）

本清单描述当前实现；已删除项目明确标记，不代表可重新安装的功能。

## 页面与入口

- 主面板：`/static/index.html`，概览、服务器、配置部署、订阅、SSH 运维、系统运维。
- 流量与通知：主面板 `#traffic-module`；旧 `/monitor` 跳转此入口，独立资源看板与主题已删除。
- 服务器工作区：在服务器列表点击主机，大弹窗内切换协议节点、SSH 运维、流量统计、任务记录、档案设置。通过 `?server=服务器ID#server-module` 直达。
- 独立“已部署节点”与“任务中心”已移除，后台任务与记录保留，在对应服务器弹窗中查看。服务器模块提供全局节点搜索、分组与标签筛选以及待关联节点管理。
- 全局订阅、面板健康检查及跨服务器升级仍在主面板；全局流量与通知配置位于主面板。

## 评估时需要区分的几件事

- 删除某个入口、删除后端能力、卸载远端脚本是三种不同范围。仅隐藏页面不会减少远端资源消耗。
- 心跳与采集复用节点 Shell + cron，独立探针已卸载；汇总与检测工作放在面板。
- 整机网卡、协议监听端口、订阅关联节点三种流量口径不同；订阅流量是已关联节点的统计汇总，不能按每个订阅用户精确计费。
- 检测结果是当前网络条件下的探测，流媒体 / AI 检测不代表实际账号登录、播放或长期可用性。
- 升级批次可以跨主机；在单机弹窗查看时只列本机相关条目，但暂停 / 继续 / 取消仍影响整个批次，界面有明确提示。
- 原来的测速模块、TCP 调优试点未加入常规自动安装；本次没有重新启用。

可直接按编号提出“保留 02–17，删除 21、23”等决定；删除之前需要结合依赖区分页面入口与后端功能。
