# HK-Lumen SSH 接入恢复记录

日期：2026-10-25。

- 面板直连该服务器的 IPv4 SSH 映射端口超时；经另一台节点转发可正常验证 root 密码、主机指纹和 SFTP。
- 面板宿主机启用 IPv6 转发后，网卡 `accept_ra=1` 不再接收路由通告，导致公网地址和默认路由缺失。改为 `accept_ra=2` 并持久化后恢复；面板容器增加独立 IPv6 出站网络。
- 目标服务器当前仅有私网 IPv6，历史公网 IPv6 的 SSH 指纹不同，未向该地址提交认证凭据。最终 SSH 使用可选节点中转，沿用经过核验的目标主机指纹。
- SSH 首次接入后安装服务器专属 Ed25519 管理密钥，并通过实际密钥登录和 SFTP 验证；面板已使用独立密钥认证。用户提供的原有登录密钥未改动。
- 目标服务器缺少协议核心与隧道进程，已按保存配置恢复固定隧道节点；节点管理脚本和独立资源探针已安装，Monitor 服务采样激活成功。
- 验收时节点在线、实际转发通过、资源探针在线，原分享链接和监听端口保持一致。维护已结束，自动运维已恢复；管理方式保持主动拉取，可在面板手动切换为 SSH 管理。
- 已部署节点统一通过「安装 / 重装命令」获取协议与已关联探针脚本，移除重复的资源探针按钮。首次安装尝试遇到协议缺失导致探针采样未就绪，故保留失败任务历史；后续恢复与验证成功。

此记录不包含认证凭据、节点链接或一次性安装命令。GitHub 未同步。
