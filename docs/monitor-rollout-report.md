# Monitor 与精简核心实施验收

验收日期：2026-10-23。状态：已部署本机生产面板，完成试点及分批推广；尚未进行 24 小时耐久验证。本文随实现源码同步 GitHub；私有运行数据与构建产物不纳入仓库。

## 验证依据

- 119 项单元/API 测试通过。
- 隔离 Alpine/OpenRC 环境真实安装并卸载 VLESS-WS-Argo、Reality Vision、Hysteria2；三协议实际转发通过，未启用面板巡检或资源 cron。
- 真实 Rust 探针经网关连接 hub，持续超过 120 秒；资源、历史、认证、关联、激活及停止核心后的故障检测通过。
- 生产试点覆盖 Alpine、Debian、amd64、arm64，完成核心切换和实际回滚；随后分批推广。生产现有节点均为 Argo，三协议兼容性的覆盖来自隔离测试。
- 验收时 10/10 节点部署任务完成、探针在线、核心切换验证成功、面板转发检查正常。
- 桌面 1440px、手机 375px 七模块切换、无横向溢出、表单保留、返回和刷新定位通过；图表触摸提示及定期刷新后保留趋势通过。
- 节点身份与链接、端口、订阅、Cloudflare、Telegram 配置摘要与改造前一致。
- 未登录资源 API 返回 401；生产 Monitor hub 未发布宿主机端口。

## 内存结论

验收时探针 RSS 为 **1.45–2.03 MiB**。这是探针进程开销，不包括协议核心、cloudflared，以及每分钟短暂运行的状态发布和管理任务。

精简构建的实验室三协议对照见 [核心测试](core-memory-benchmark.md)。线上负载、采样时刻及系统不同，个别节点的核心 RSS 未下降，不能套用统一节省比例。固定 1.13.21 的补充测试通过三协议转发；官方与精简文件编译器版本不同，其内存数据仅供参考。1.13.21 arm64 发布文件已构建，但本轮没有该版本的 ARM 实机验证。

## 恢复与保留

节点可从“核心版本 / 回滚”选择 `rollback`；上一核心槽位在 `/usr/local/etc/sing-box/core-rollback`。回滚先用上一核心验证当前配置，不自动覆盖用户当前配置。管理脚本另保留一份 `management-rollback`。本机保留改造前镜像 `auto-argo-node:pre-monitor` 及 Nginx WebSocket 改造前配置，均为局部恢复材料，不是整机快照。

探针卸载命令由资源卡片提供，保留协议；已启用管理的节点退回旧心跳方式。面板数据库已有新增字段和历史，不应在恢复旧镜像时删除这些数据。详细构建、接入、诊断及限制见 [运维说明](monitor-operations.md)。
