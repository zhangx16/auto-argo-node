# Monitor 主题、独立看板与三网延迟

所有全局资源、流量、Telegram 通知设置与主题管理统一在 `/monitor`，沿用主面板登录。服务器模块顶部的资源 / 流量、SSH 快捷分类已删除，左侧入口和服务器弹窗内的单机操作保留。主页面不再显示全局流量模块、Telegram 表单或今日流量卡片；旧 `#traffic-module` 地址跳转 `/monitor#traffic`。

## 主题管理

看板顶部可选择主题、浅色 / 深色 / 跟随系统，或打开主题管理：

- 内置管理看板保留主机管理链接、分组、拖动排序和流量额度操作。
- GitHub 安装：填写主题仓库地址，下载最新正式 release 的 `theme.tar.gz`。
- 本地上传：支持上游实际发布的平铺包，以及 `short/theme.json + short/dist/` 目录包。
- 可先预览主题（不改变站点设置），再使用、更新、删除主题，以及根据 `theme.json.config` 设置布局、公告、显示选项等。更新 / 重装保留配置，删除当前主题回到内置管理看板。
- 主题及站点显示设置保存在面板数据目录 / 数据库，所有设备共享；明暗偏好、第三方主题自己的卡片 / 地球偏好按浏览器保存。
- 内置卡片在大屏默认三列，可设置二至四列；中等屏幕两列，手机一列。紧凑列表仍可单独选择。

已用真实发布包验证：

| 主题 | 版本 | 已验证 |
| --- | --- | --- |
| Monitor 官方默认主题 | 1.4.2 | 安装、读取实时数据、手机显示、回到管理看板 |
| Rakugaki | 1.18.1 | 手绘页面、地球与节点、国旗 / 字体路径、详情路由、主题配置与浏览器偏好适配、手机显示 |

第三方主题运行在独立的沙箱 iframe，拿不到管理页面 DOM / Cookie。兼容层只提供上游的 `me`、监控节点、指标 / 延迟历史、主题显示配置；过滤 IP、令牌、主机私有备注与原始网卡计数。修改 SSH / 部署 / 后台设置的请求被拒绝。主题原来的管理 / 登录链接隐藏，使用外层页面的管理入口。

主题包只接收常规文件与目录；拒绝绝对路径、目录穿越、软链接 / 硬链接、重复路径和损坏的 gzip。压缩包最多 32 MiB，解压内容最多 64 MiB，单文件最多 8 MiB、最多 2000 项。不执行主题包中的任何服务器程序。

由于采用现有面板的只读桥接，主题的数据刷新为 10 秒，历史请求最多六个并行并有缓存；不开放上游独立后台的完整管理接口。非标准接口、外部字体 / 资源或其它站点插件可能需要单独适配，不承诺任意第三方主题均兼容。

## 安徽三网 TCP 延迟

使用 Monitor agent 原有 TCP probe，不新增远端脚本或常驻进程。默认三条目标：

| 名称 | 目标 | 间隔 |
| --- | --- | --- |
| 安徽电信 | `ah-ct-v4.ip.zstaticcdn.com:80` | 60 秒 |
| 安徽联通 | `ah-cu-v4.ip.zstaticcdn.com:80` | 60 秒 |
| 安徽移动 | `ah-cm-v4.ip.zstaticcdn.com:80` | 60 秒 |

在 `/monitor` 三网 TCP 延迟区修改地址和采样间隔，并应用到全部已接入探针。默认新主机自动加入。限制采样间隔至少 30 秒，保持轻量；单机展开后按需读取最近一小时的有效延迟和 TCP 失败率。Rakugaki 的延迟卡片和详情曲线读取同一份历史记录。

探测表示从服务器连接上述 TCP 端口的耗时，不等于 ICMP 延迟、面板到节点的转发延迟或带宽测速。超时如实记录失败，不触发协议节点的自动重装。

应用时复用已有线路 ID；失败重试不会重复创建已成功线路；减少线路时停用对应探测，保留历史。私有 hub 服务凭据仅额外允许探测任务与节点探测关联接口，仍拒绝后台设置等其它管理路径。

## 部署与测试

- 新增服务：无。节点 agent 二进制不变，只更新面板及私有 hub 的服务接口白名单。
- 主题文件：面板数据目录下 `monitor-themes/<short>/`，无需改动节点。
- 配置：`monitor_themes`、`monitor_latency` 数据库设置；主题上传 / 应用 / 配置与探测配置均验证管理员会话和请求来源。
- 验证包括恶意压缩包、配置校验、权限、无敏感字段的桥接、真实官方 / Rakugaki 包，以及实际 Monitor hub + 现有 agent 的三条本地 TCP 探测。

参考：[上游主题开发规范](https://monitor-document.pages.dev/dev/theme)、[上游主题目录](https://monitor-themes.pages.dev/)、[Rakugaki](https://github.com/akanotanin/monitor-theme-rakugaki)。

## Nginx 反代适配

原主面板使用 `frame-ancestors 'none'` / `X-Frame-Options: DENY` 时，不能直接承载主题 iframe；全站 CSP 不必放宽。在 HTTPS server 内引入 [nginx-themes.conf](../integrations/monitor/nginx-themes.conf)：仅主题视图改为同站嵌入，仍禁止直接联网与提交表单；主题上传接口单独允许 33 MiB 的 multipart 请求，包内容仍受后端 32 MiB 上限约束。其余页面保留原安全策略。
