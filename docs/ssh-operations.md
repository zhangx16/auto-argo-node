# SSH 运维

SSH 是可选的按需管理通道。资源探针继续负责心跳、资源与流量，面板继续做实际转发验证；服务器原有 SSH 服务用于执行运维任务。首次发布不会使用聊天中的密码、不会自动切换现有服务器。

## 首次接入

1. 打开左侧 **服务器 → SSH 运维**。资源看板中的服务器自动列为「待填写 SSH 凭据」，也可新增独立 SSH 服务器。
2. 点击「填写首次凭据」，输入实际 SSH 地址（IPv4、IPv6 或 DDNS）、映射端口和 **root 密码或私钥**。首版以 root 登录，不实现 sudo 交互。
3. 读取并核对主机指纹，再验证保存。每次连接均验证所保存的主机密钥；DDNS 地址每次重新解析，地址变化不会绕过主机身份验证。服务器重装后需核对新指纹再更新。
   「SSH 连接通道」默认本机直连。目标线路直连超时时可选择另一台服务器上的节点中转；选定通道用于指纹读取、凭据验证、SFTP、任务与密钥验证，不自动降级到直连。中转在面板临时启动，SSH 连接结束即退出。中转节点失效或删除后会明确失败，需手动更换；不能选择当前服务器的关联节点，避免重启服务器时切断自己的管理通道。IPv6 出口排查见 [面板 IPv6](panel-ipv6.md)。
4. 首次密码接入可勾选「验证后安装独立管理密钥」。系统为每台服务器生成独立 Ed25519 密钥，先追加公钥、实际用新私钥登录成功，再切换面板认证方式。原有密码和其他密钥不被关闭。以后更新配置时留空保留已有凭据。
5. 如有自定义 AuthorizedKeysFile、只读 home 或不接受 Ed25519 的 SSH 服务，请使用已有可用私钥；自动配钥按 root 标准 `.ssh/authorized_keys` 路径操作，验证失败会保留当前认证配置。

连接凭据和自定义脚本使用独立用途的 Fernet 密钥加密，密钥从现有 `data/secret.key` 派生；接口不返回密码或私钥。恢复数据需同时保留数据库和对应 secret.key。管理密钥公钥带服务器专属标记，轮换只移除之前由面板管理的公钥；撤销前须切回主动拉取。撤销不删除其他登录密钥。主动拉取模式下还可清除面板保存的密码或私钥；存在面板专属密钥时需先撤销。

## 关联节点与管理方式

自动生成的 SSH 记录首次沿用资源探针的节点关联，之后通过「调整关联节点」明确修改，不会反复覆盖人工关联。节点只能关联一个 SSH 服务器。切换前会通过远端节点运行凭据核对身份，避免同名服务器或节点 ID 碰撞导致误操作。

「切换为 SSH 管理」要求关联节点已绑定、管理脚本至少 v8、没有正在执行的配置任务。旧式巡检依赖管理 cron，应先迁移到独立 Monitor 探针；原本未启用主机监控的节点可以继续仅做面板转发检测。

切换时等待节点当前任务结束，移除对应的管理 cron，保留其他 cron、协议服务和探针。切回主动拉取恢复这些管理条目。面板在 SSH 模式中拒绝原轮询通道领取配置任务和修复授权，防止同时操作。切换/服务重启进入 10 分钟节点维护，自定义维护进入 30 分钟维护；已有维护不被缩短，可在故障详情中提前结束。

## 可用操作

- **只读诊断**：系统、初始化方式、内存、磁盘、进程、监听、Linux capabilities 和已关联节点的本地诊断。不会输出命令行、配置文件或凭据。
- **执行节点任务**：通过 SSH 按需启动已有一次性管理脚本，沿用配置版本、原有协议安装逻辑、结果回调、回滚和转发验证。
- **首次安装此节点**：先在配置部署页生成节点，在 SSH 页面关联到服务器，再执行尚未绑定节点的安装命令。首次安装后可切换 SSH 管理。资源探针仍独立安装。
- **重启协议服务**：作用于该服务器共用的 sing-box；原有节点配置不重写，任务后重新做转发检测。
- **自定义维护脚本**：以 root 非交互执行管理员输入的 Shell，支持复杂诊断与维护。脚本须自行处理交互选项；此功能不是浏览器终端。
- **管理密钥安装、轮换、撤销**：结果通过真实 SSH 认证验证。

SSH 模式下，已有配置/升级/卸载任务和确认的故障按需触发 SSH 执行，复用维护模式、修复次数限制及现有任务队列。健康服务器不会为采集资源而反复建立 SSH 连接。协议安装/升级继续使用原管理库，因此仍需服务器能访问面板及所需下载源；独立 SSH 诊断、自定义维护和服务重启不依赖节点访问面板 API。当前不是完全离线部署方案。

## 任务恢复与容量

面板最多同时运行 2 个 SSH 检查/执行工作线程，每台服务器只允许一个未完成任务。任务最长执行 25 分钟；远端使用一次性 Shell、timeout 和有界 tail，执行结束即退出。原始输出保留最后 128 KiB，面板保留过滤后的最后 24000 字符；不会限制下载文件或安装二进制的大小。自定义脚本输出仍需管理员控制，常见敏感字段过滤不保证识别任意秘密文本。

任务上传到 root 专有的 `/var/lib/argo-panel-ssh/<任务ID>`，通过唯一启动标记保证同一任务不重复启动。面板重启或 SSH 断开后先读取原任务结果；已经启动却缺少执行标记时显示「结果未知」，不自动重放。结果确认后清理远端任务文件；结果未知时保留以供恢复。

失败后暂停该服务器自动运维。先查看记录、重新检查结果；只有确认远端相关进程已结束才能结束追踪。已确认服务器重装、旧任务无法取回时，可选择「服务器已重置：放弃旧任务」；此操作不执行远端清理，自动运维仍保持暂停。检查实际状态后再点击「恢复自动运维」。不能为了消除错误而自动忽略主机指纹变化。任务结果复用 TG「部署与任务结果」通知类别，不发送脚本正文、凭据或原始输出。

面板保留最近 300 个已完成任务；未完成任务不清理。SSH 配置与任务记录放在现有 SQLite 中，不引入新的数据库或常驻节点代理。

## 已验证与边界

已在隔离 Debian 和 Alpine SSH 环境验证密码登录、SFTP、固定指纹拒绝、断连后结果恢复、缺失执行标记时不重放、管理 cron 切换及其他 cron 保留、实际一次性管理脚本的 SSH 执行标记、管理密钥验证/轮换/撤销、其他密钥保留，以及超过日志容量的正常文件写入。ARM 实机、不同供应商的 SSH 配置和真实公网断网需在用户录入凭据后做小范围验证。

SSH 给予当前 root 账号已有的能力，不突破宿主机限制。网络调优仍按 [已保存方案](network-tuning-proposal.md) 暂缓，不会因启用 SSH 自动修改内核、防火墙或路由。

## 服务器重装后的恢复

可优先使用「服务器 → 档案 / 恢复 → 重装恢复向导」。需要手动安装时，在「已部署节点」展开对应记录，点击「安装 / 重装命令」。生成命令不会立即排队安装或撤销当前管理凭据；实际执行后才交换一次性凭据，并按保存的配置排队安装。命令有效期 24 小时、成功使用一次即失效；存在未完成配置任务、卸载或配置回滚时先处理原任务。固定隧道使用原绑定和保存配置恢复，临时隧道可能重新分配域名；Reality 重装可能生成新密钥，恢复后从面板读取最新链接。

已关联 Monitor 的节点会同时显示独立探针命令，先执行协议安装，再执行探针安装。记录 ID、订阅关联和标签沿用原记录。SSH 管理模式下恢复脚本仅执行一次，继续由 SSH 接管后续任务，不新增主动拉取 cron。重装后如服务器 SSH 指纹已改变，须核对并更新 SSH 接入配置。
