# Argo 面板 UI 设计约定

## 目标与主参考

让用户在同一控制台查看节点状态、配置部署、管理订阅和流量通知。用户于 2026-10-22 明确选择 shadcn/ui。

- 主参考：[shadcn/ui dashboard-01 / new-york-v4](https://ui.shadcn.com/view/new-york-v4/dashboard-01)。
- 登录参考：[同系列 login-01](https://ui.shadcn.com/view/new-york-v4/login-01)。
- 取用方式：保存实际渲染 HTML 和样式表，读取颜色、字体、圆角、间距和布局，再将其设计映射至现有原生 HTML 组件。保持原有 JavaScript、表单字段与 API 契约，不引入 React 或客户端构建链。
- 主参考代码为 shadcn/ui；本地 Geist 子集使用随附 OFL 授权。中文使用 PingFang SC / Hiragino Sans GB / Microsoft YaHei 系统回退，避免依赖外部字体服务。
- 未选择 TailAdmin：当前面板不需要其多层商业后台导航。未选择 Tremor：当前 API 没有时间序列接口，不用虚构趋势图填充空间。

## 页面结构与依据

1. 侧边导航和顶部面包屑：来自 dashboard-01 的浅灰侧栏与内嵌白色内容区。移动端改为可关闭导航抽屉。
2. 节点概览：参考指标卡，使用实际已部署节点数、在线心跳数、今日流量和待执行任务数；沿用已有响应，不新增轮询计时器；流量复用现有 30 秒查询，仅在概览可见或流量模块展开时刷新。
3. 配置部署：参考同系列表单控件，按内容组织两列，手机单列；保留 Argo、Reality 和 Hysteria2 的条件字段。
4. 已部署节点、部署任务：主模块直接展开，节点和任务条目保留折叠。协议使用中性标签，健康状态保留必要语义色。
5. 订阅、外部节点、链式代理：保留已有弹窗和选择流程，以同一组按钮、输入、分隔和列表样式呈现。
6. 流量与通知：保留真实端口统计、采集状态、Bot 设置和通知测试操作，主模块直接展开，保留各节点明细折叠。
7. 登录：参考 login-01 的居中紧凑布局，保留账号密码认证，不增加注册、找回密码或第三方登录入口。

## 设计语言与既定决策

- 浅灰侧栏、白色内容区、黑色主操作、细灰边框；避免继续混用旧暖橙色表单。
- 主要边距以 16px 为单位，内层 24px / 页面 32px；控件 8px 圆角，容器 14px，状态标签全圆角。这三类半径来自参考，覆盖 skill 的默认“两种圆角”限制。
- 指标卡保留参考的轻微白灰渐变；其余表面纯色。此处的渐变为主参考既定设备，不是新添加的背景装饰。
- 一组轻微静态阴影用于参考中的卡片和控件，独立浮层阴影用于对话框。
- 五档文字：12、14、16、24、32px。后台密集表单使用参考中的 14px；说明使用 12px 且检查对比度。主标题 24px，状态数字 32px，手机数字 24px。
- 运行状态使用既有绿色、红色、蓝色和琥珀语义色；协议分类本身不依赖颜色区分。
- 不展示没有来源的增长率、曲线、在线保证或使用人数。
- 保留先前要求的纵向业务模块顺序。侧栏使用独立模块路由；右侧只呈现所选模块，保留旧锚点链接兼容、前进后退及未提交表单。
- 表单和数据刷新逻辑沿用现有实现，所有破坏性操作继续使用原有确认流程。

## 可调参数映射

所有参数集中在 `app/static/deploy.css` 的一个 `:root` 中，属于参考值或现有产品语义色。

| 参数 | 映射 | 来源 / 范围 |
| --- | --- | --- |
| `--gap` | 16px，主要间距按倍数衍生 | 主参考 |
| `--fs` | 14px，12/16/24/32 按固定倍数衍生 | 主参考 |
| `--radius` / `--radius-card` | 8px / 14px | 主参考 |
| `--measure` | 72ch，长说明行宽 | 产品中文内容约束 |
| `--ink` / `--surface` / `--line` | 0% / 100% / 92% 的中性色亮度 | 主参考颜色映射 |
| `--edge` | 1px | 主参考 |
| `--shadow` | 0.05 的静态阴影 alpha | 主参考 |
| `--room` | 1.5 个 gap 的模块间距 | 主参考 24px |
| `--dur` / `--ease` | 150ms / cubic-bezier(.4,0,.2,1) | 主参考交互 |
| `--hue` | 不绑定，中性主色不需要色相调节 | 显式未绑定 |
| `--ratio` | 不绑定，参考采用固定而非等比字号 | 显式未绑定 |

颜色桥接限定于中性正文、背景、边框，语义告警色独立保留。减少动态效果设置将时长置零，取消平滑滚动。

## 条件表面与锚点

- `shell/sidebar` / `shell/header`：桌面收起、手机展开、遮罩关闭、Esc 关闭与焦点回归。
- `overview` / `overview/metrics`：空数据、真实计数、加载占位。
- `deployment`：三种协议、临时/固定隧道、参数错误、安装命令。
- `nodes` / `tasks`：无记录、折叠、运行状态、端口待应用、失败任务、日志、删除确认。
- `subscriptions`：外部导入预览、订阅编辑、格式预览、停用、链路编辑和删除。
- `traffic`：未采集、采集过期、汇总、通知未配置、发送失败和成功。
- `dialog/<现有弹窗 ID>`：命令、节点编辑、订阅编辑/预览、外部导入和编辑。
- `login/brand` / `login/form`：默认、键盘焦点、登录错误、提交中。

## 预览与交付

设计草稿位于本机 `artifacts/ui-redesign/draft`（不跟随 Git 发布），含相对路径 HTML/CSS/JS 和本地字体，无需构建，可断网打开。演示节点、账号和日期全部标为设计数据，不取用生产凭据。

审阅工具 `draft-kit.js`、`review-config.js` 及 `selection.json` 仅在草稿使用；正式页面不包含这些工具，不发送审阅数据。草稿 `/__select` 由 skill 提供的标准库服务器记录；离线文件模式无法保存服务器端选择。

运行组件为现有 `deploy-ui.js`、`subscriptions.js`、`telemetry.js`、`login.js` 和新增 `shell-ui.js`。新增脚本只处理导航、焦点与既有事件的状态汇总。

验证记录随本次浏览器审阅更新：375 / 768 / 1440px，并覆盖 479/480、767/768、1199/1200px 的布局边界；检查各模块与弹窗、水平溢出、键盘导航、Esc、可见焦点和文字对比度。样例预览不连接生产 API，其登录和数据写入只模拟；正式页面使用原 API。

本次验证结果：浏览器功能冒烟通过；52 个页面状态/滚动位置的审阅覆盖无文字对比度失败，未发现未知图片背景对比度。小屏触控目标检查通过；原生 Enter 打开导航、Esc 关闭及焦点回归通过。参考固定的 8/14px 圆角与全圆标签/状态圆点、两类阴影、五档字号保留。

## 流量图表与地区 / 用量扩展（2026-10-22）

沿用上述参考，不重新选择配色或导航。新增锚点 `traffic/chart`、`dialog/region` 和订阅内的 `.subscription-usage`。图表横轴 UTC 日期、纵轴字节用量，黑色 IN / 中灰 OUT 堆叠柱；图表自身不是第二组卡片网格。不渲染假趋势、不对未采集日期插值；原生 SVG title 与每日数据表提供精确值和非指针入口。图表尺寸通过 ResizeObserver 适配，无图表运行时依赖。表单使用原有控件与字阶，数据表在窄屏容器内滚动。国家/地区可通过本地库自动识别或表单覆盖，国旗属于内容，地区结果不代表线路质量。订阅进度条只展示共享节点累计值与参考额度，明确缺失和过期采集，不承诺独立用户计费。

### 资源看板扩展

主模块直接展开，沿用现有节点折叠卡片与中性 progress 控件；放在订阅与流量通知之间。资源均为真实心跳样本，24 小时趋势使用同色散点，不插值补齐离线区间；手机端指标单列。

### 主模块导航调整

所有侧栏对应主模块均直接展开，点击侧栏平滑定位到标题并避开固定页头；移动端关闭导航并将焦点移至标题。节点、任务、订阅及资源条目的详细信息继续按需展开。订阅和流量刷新以模块是否进入视口为准，导航到对应模块时立即刷新。

## Monitor 资源视图适配（2026-10-23）

- 用户指定 Monitor 为资源看板参考；复用其主机卡片、资源条、速率与历史详情结构，许可位于 `integrations/monitor/licenses/`。
- 沿用已约定的原生 HTML/JavaScript 与 shadcn 变量，不引入第二套 React 路由或登录。资源采集与历史实际来自内部 Monitor hub，并非静态模拟。
- 资源页按主机组织，关联协议单独列出；CPU/内存/网卡显示真实数据。主机网卡用量不替代端口/订阅用量。
- 非活动模块退出焦点顺序；概览卡片仅在概览页显示；资源图表仅在资源模块可见时刷新。

### 服务器流量额度替代趋势入口

保留既有卡片、字号、进度条和弹窗组件；新增锚点 `resources/host-traffic`、`dialog/host-traffic`。资源卡片不再显示趋势按钮或图表，改为服务器周期用量与额度占比。未配置额度、数据不可用、超额和编辑失败均有明确文本；进度条上限 100%，实际百分比允许超过 100%。弹窗支持键盘与原生 Escape，显示当前主机名称，GiB / TiB 单位明确标注。

资源流量紧凑化：按用户反馈与 CPU、内存、磁盘共用 `.resource-metric` 和同一网格；只展示名称、已用 / 总额度、占比与进度条。剩余、方向、重置日及周期开始信息不在主机卡片重复展示，额度设置仍通过原按钮打开。

### 资源主机拖动与分类

沿用已有表单、弹窗及中性色彩；卡片增加名称前的六点拖动手柄与“分类”操作，分类标签与系统信息共用一行。增加分类筛选与数量，不增加第二层卡片。排序支持鼠标、触摸、键盘方向键及 Home / End，Escape 取消；手机手柄触控区域至少 44px。拖动仅占用手柄，卡片其余区域仍可滚动与操作。
